# Fast judgments, deeper help — 60-second pilot

Audience: developers. One worked ticket stream. This is a standalone test of the
central information flow, not the complete 7:30 explanation or a live agent recording.
No pseudocode. No measured inference-speed/cost claims.

Visual question: what changes when a familiar-looking ticket needs more evidence?
Aha: the helper returns facts; System One remains the driver of the next judgment.

## Visual beats (final timing follows generated audio)

1. **Need an outcome**: a ticket slides into a field with three possible categories.
   Reveal the path from a category to an actual assignment receipt.
2. **Routine case**: “Charged twice” moves to the cyan System One judgment.
   Payments is selected; green Pi execution produces a confirmation.
3. **Change the facts**: the same ticket becomes “Payment failed. Service is down.”
   Fade the previous result, retain the decision driver, expose missing evidence.
4. **Consult**: reveal the amber helper only now. A small packet follows the downward
   consultation path. Label “enabled by you” and “permitted tools”.
5. **Gather evidence**: order and service checks complete in sequence. Their results
   join an evidence packet; an outage is confirmed in this illustrative scenario.
6. **Return and decide**: evidence travels back up to System One. The category changes
   to SOS under this product's policy. Pi executes the assignment and creates a receipt.
7. **Reusable foundation**: zoom out to the purple Turbo coordination boundary and green
   Pi foundation. Other Pi extensions and connected MCPs feed shared capabilities.
   Label the developer's supplied policy and relevant state.

## Visual grammar

Dark background; cyan System One, amber System Two, purple Turbo, green Pi,
blue application facts/policy. Start with ordinary-language labels; introduce
names as they are spoken. Keep a visible packet moving only when information changes
hands. Use Text and vector geometry, no TeX dependency or copied 3b1b assets.

## Production

Manim Community (Cairo), 1920×1080, 30fps. Kokoro 82M 8-bit via MLX Audio;
stock voice af_heart. Short WAV paragraphs with exact silent holds added to fill
60 seconds. Verify generated audio durations before fixing scene cuts.
